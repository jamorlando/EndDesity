# 团队工作日志与智能复盘管理系统 —— 前端 UI 设计规范与视觉风格指南（文房四宝高定版）

## 1. 核心设计灵魂：文房四宝 · 经世致用

按照甲方（用户）专属定制与最高美学决断，本系统彻底跳出通用 SaaS 的粗陋同质化与古风无脑堆砌的两个极端，确立了**“以文房四宝为器，以《瓷韵》留白为骨，以山水苍松为魂”**的国际大奖级（Awwwards / Apple Design Award）黑白水墨现代工程美学体系：

- **大象无形，计白当黑**：采用极度纯净的雪宣留白底色（`#FAFAFC`），配合 **0.038 电影胶片微噪点（Film Grain Overlay）**，消除数字生硬塑料感，展现徕卡大片暗房与古法手工宣纸的哑光质感；
- **山水松树，苍劲风骨**：以**“左崖苍松挺立、中景长桥流水、远景群山叠嶂”**的真实黑白传世水墨大画作为全局画境背景，配合穿林流雾与鼠标 2.5D 空间景深微视差；
- **国际顶级交互工艺**：卡片采用 **Linear / Apple 招牌式的 Spotlight 鼠标聚光微光追踪** 与 `24px` 高精度磨砂毛玻璃（Backdrop Blur），所有分割线均为 `0.5px` 纳米级精密微线。

| :--- | :---: | :--- | :--- |
| **卷一 · 案牍实录** | **【笔】**<br/>兼毫挥毫 | **工作日志工作台** (`/worklogs`) | 研发人员每日“提笔录卷”，实录【今日功绩】、【遭逢关隘】与【明日之计】；支持多工程过滤、全员状态筛选、工时统计与纯安全附件校验。 |
| **卷二 · 四省推演** | **【纸】**<br/>澄心铺卷 | **KISS 敏捷复盘驾驶舱** (`/retrospective`) | 团队铺开宣纸画卷，布下**“守正·Keep（苍松常青）、迁善·Improve（长桥跨流）、开新·Start（群峰竞秀）、止损·Stop（悬崖勒马）”**四立轴大阵，支持行动项任务认领与排期流转。 |

| **卷四 · 灵犀题跋** | **【砚】**<br/>研墨钤印 | **AI 智能复盘诊断舱** (`/ai-insights`) | 砚池凝香；大模型（DeepSeek / 通义千问）双通道题跋立论、Map-Reduce 提取共性阻塞根因，重重加盖御制朱砂印信（“允准入库”），并支持一键导出 Word 归订单。 |

## 3. 核心设计令牌 (Design Tokens)

### 3.1 颜色系统
* **雪宣底色 (Snow Paper)**：`#FAFAFC`（全屏纯净主基底）；
* **磨砂卡片底 (Frosted Glass)**：`rgba(255, 255, 255, 0.84)`，`backdrop-filter: blur(24px)`；
* **Spotlight 聚光 (Cursor Glow)**：`radial-gradient(400px circle at (x,y), rgba(0,0,0,0.05), transparent 50%)`；
* **朱砂御印 (Vermilion Cinnabar)**：`#B82823`（状态验收印鉴、紧急警示红标、点睛圆印）；
* **正文墨色 (Pure Ink)**：标题采用 `#111111`，正文采用 `#2A2A2A`，次要标注采用 `#737373`。

### 3.2 字体排印 (Typography)
* **大字草书题名**：`Ma Shan Zheng`、`STKaiti`、`KaiTi`、`楷体`；
* **文人竖排对联与正文**：`Noto Serif SC`、`Source Han Serif SC`、`Songti SC`；
* **英文与数字辅助**：`Cinzel`（古典衬线）+ `-apple-system, BlinkMacSystemFont`。
